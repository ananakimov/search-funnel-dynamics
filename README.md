# Воронка поиска — динамика

Статический сайт (без сборки и серверной части). Сравнивает выгрузки первой формы между неделями:
кто из поисковиков что сделал, как менялись этапы, какие объекты и новые задачи пришли в этапы.

## Как пользоваться каждую неделю
1. Выгрузить из первой формы xlsx (желательно без фильтра по этапам — тогда видно, куда ушла задача).
2. Открыть сайт, ввести пароль, нажать «Загрузить выгрузку», проверить дату, «Сохранить». Фильтры и история выгрузок — кнопки в верхнем меню.
3. Чтобы выгрузку видели коллеги: значок истории (часы) → «Опубликовать для всех» → «Скачать vault.json» → заменить файл `vault.json` в репозитории.

## Как это защищено
`vault.json` — выгрузки, сжатые и зашифрованные AES-GCM-256, ключ из пароля (PBKDF2-SHA256, 250 000 итераций).
Без пароля файл не читается. Используйте длинный пароль. Выгрузки, загруженные кнопкой, лежат в браузере
тоже в зашифрованном виде.

## Файлы
- `js/core.js` — разбор xlsx, область отслеживания, сравнение выгрузок (порядок этапов — в начале файла)
- `js/vault.js` — шифрование и локальное хранилище
- `js/app.js`, `css/app.css` — интерфейс
- `tools/build_vault.py` — первичная сборка vault.json из xlsx (нужна один раз)
